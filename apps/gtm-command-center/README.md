# Restaurant Ops Command Center (MVP)

Next.js app for the restaurant vertical slice: **menu → order submission → kitchen execution**.

## Quick start

From workspace root:

```bash
npm run restaurant:dev
```

Or from this folder:

```bash
npm run dev
```

Open http://localhost:3000.

## Build + lint

From workspace root:

```bash
npm run restaurant:build
npm run restaurant:lint
```

## Current MVP scope lock

1. Browse menu items
2. Add items to an order
3. Submit order
4. Show order in kitchen board status lanes

Anything outside this flow is backlog unless it blocks the slice.
