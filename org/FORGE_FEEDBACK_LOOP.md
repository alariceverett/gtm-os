# Forge Feedback Loop (Operational)

## Cadence
- **Daily (heartbeat):** check `EJKIV/Forge` latest commit and classify impact.
- **On every meaningful local change:** capture implementation gap notes.
- **Weekly:** file one consolidated Forge issue with:
  - confirmed gaps
  - proposed fix shape
  - field evidence from usage

## Trigger Conditions (Immediate issue to Forge)
1. Security/control gap discovered
2. Delegation principle drift from runtime behavior
3. Bootstrap/deployment ambiguity causing operator friction
4. Missing product scaffolds that block execution speed

## Report Template
- What happened
- Why it matters
- Proposed solution
- Minimal reproducible evidence
- Impact if unaddressed

## Ownership
- Owner: Al (main agent)
- SLA: same-day for critical, weekly batch for non-critical
