# CONSOLIDATE_AND_HARDEN_PLAN.md

## What it means (practical)
Consolidating and hardening means pausing process expansion and focusing on reliability, consistency, and measurable outcomes with the current operating stack.

## 7-day execution mode
1) Freeze net-new process frameworks.
2) Run existing gates/protocols consistently every cycle.
3) Prioritize bug fixes, integration quality, and UX coherence over new features.
4) Verify and publish proof for each cycle (routes, golden path, KPI impact).

## Daily checklist
1. Route truth check (all critical URLs HTTP 200).
2. Golden-path replay pass (targeting -> actions -> relationships -> pilot).
3. Interaction debt check (clicks/context switches not regressing).
4. KPI snapshot update (4 canonical metrics).
5. Ops Review Center update (material changes, blockers, next actions).

## Hardening focus areas
- Orchestrator stability (no idle gaps with unblocked work)
- Recommendation quality consistency (rationale/confidence/next action)
- UI consistency and readability across pages
- Data integrity across comms/actions/relationships/pilot

## Exit criteria for consolidation window
- 3 consecutive cycles with no route regressions
- Golden path pass rate >= 95%
- No unresolved SWARM_GAP/AUTONOMY_GAP incidents
- Operator confidence trend stable or improving
