## Proposed Fix

### Option A: Agent Heartbeat Protocol (Recommended)
- Subagents must "check in" every 15 min via lightweight signal
- Orchestrator considers agent "lost" if no check-in for 30 min
- Lost agent → auto-query session history → determine completion status

### Option B: Completion File Contract
- Subagents write `COMPLETION.json` to workspace on finish
- File contains: status, artifacts created, build result, blockers
- Orchestrator scans for these files every heartbeat

### Option C: Workspace State Reconciliation
- Orchestrator maintains "expected files" list per task
- On heartbeat: verify expected files exist → auto-mark complete
